# Процедурная реализация (КТ2)

## Язык и версия
Python 3.12

## Команды сборки и запуска
Для запуска программы используется командная строка:

    python main.py

## Входные данные
Тестовые данные находятся в файле `example_data.json`:
- `test_request_valid`, `test_request_invalid` — заявки для алгоритма 1 (`check_request`);
- `test_catalog`, `test_query_tags` — каталог моделей и теги запроса для алгоритма 2 (`search_models`).

Поля структур данных соответствуют логической модели:
- «Заявка»: `id_заявки`, `id_товароведа`, `id_модели`, `дата`;
- «3D-Модель»: `id_модели`, `id_товара`, `путь_к_файлу`, `формат`, `статус` (поле `название` берётся из связанной сущности «Товар» через `id_товара`).

## Ожидаемый вывод
При запуске `python main.py` вывод должен быть следующим:

    Заявка валидна: False
    Не хватает полей: ['id_модели', 'дата']

    Найдено моделей: 2
    - Стол (совпадений: 2)
    - Стул (совпадений: 1)

Если вывод совпадает — программа работает корректно.
