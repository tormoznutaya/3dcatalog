# Процедурная реализация (КТ2)

## Язык и версия
Python 3.12

## Команды сборки и запуска
Для запуска программы используется командная строка:
python main.py

## Пример входных данных и ожидаемый вывод
В файле `example_data.json` содержатся тестовые данные.

Для проверки заявки:
Вход: `test_request_invalid` (не хватает полей).
Ожидаемый вывод: `Заявка валидна: False, Не хватает полей: ['description', 'price']`

Для поиска по тегам:
Вход: `test_catalog`, `test_query_tags` (["дерево", "офис"]).
Ожидаемый вывод: 
Найдено моделей: 2
- Стол (совпадений: 2)
- Стул (совпадений: 1)
