# 3D Product Catalog

Каталог трёхмерных моделей товаров для интернет-магазина.

**Автор:** Дындарь Маргарита Всеволодовна  
**Группа:** ИКБО-31-24

## О проекте

Система для подготовки, хранения и публикации 3D-моделей товаров. Позволяет загружать модели, привязывать их к карточкам товаров и отображать покупателю в браузере.

## Структура

- `docs/` — документация
- `src/` — исходный код
